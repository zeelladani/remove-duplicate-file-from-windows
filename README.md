Duplicate File Reviewer
🚀 Get started in just 4 steps!

1️⃣ 📥 Download
Download this repository as a ZIP file.

2️⃣ 📦 Extract
Unzip the downloaded file anywhere on your computer.

3️⃣ 📂 Copy the files
Copy these two files:

📄 ReviewDuplicates.bat
📄 ReviewDuplicates.ps1

Paste both files into the folder where you want to check for duplicates.

4️⃣ ▶️ Run
Double-click:

▶️ ReviewDuplicates.bat
🔍 What happens next?

The tool will automatically:

📁 Scan the selected folder
↳ 🔎 Scan all subfolders
↳ 🧹 Find files with duplicate naming patterns
↳ 🖥️ Open Windows File Explorer
↳ 🖼️ Select the detected files so you can check them using thumbnails

⚠️ Good to know

🛡️ Nothing is deleted!
This tool is only for finding and visually reviewing duplicate files.

💡 For the best experience, switch File Explorer to:

View → Extra large icons 🖼️

so you can easily verify the files before taking any action.
